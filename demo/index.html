Rasta — رستہ

A walkthrough of the real app: Islamabad & Rawalpindi Metro Bus and CDA bus routes.

These are real screenshots of the working app, captured from a running build — not mockups. They were taken in headless Chrome at phone width. Chrome's --window-size includes browser chrome, so the rendered page is a little wider than the captured image and some right-edge text is cropped in these pictures only; the layout itself measures 0px horizontal overflow at 420 px across all seven screens. Open index.html to see it uncropped.

Rasta is not a live bus tracker and cannot be one: no GTFS feed, no real-time API and no open data portal exists for these services. Journey times are modelled from distance, and disputed information is labelled rather than hidden. See README.md.
